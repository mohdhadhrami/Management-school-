# نظام سجل الدرجات الإلكتروني الاحترافي

نظام متكامل لإدارة درجات الطلاب في المدارس باستخدام التقنيات الحديثة.

## المميزات الرئيسية

### 1. التصميم الاحترافي
- واجهة مستخدم عربية متكاملة ومتجاوبة
- تصميم حديث يعمل على جميع الأجهزة (حاسوب، تابلت، هاتف)
- ألوان متناسقة وواضحة مع تدرجات جذابة
- أيقونات Font Awesome للتوضيح

### 2. الهيكل التنظيمي
- شريط جانبي للتنقل السريع بين الأقسام
- شريط علوي بتصميم جذاب
- لوحة تحكم رئيسية مع إحصائيات مباشرة
- صفحات منفصلة لكل وظيفة

### 3. إدارة الصفوف الدراسية
- إضافة صفوف جديدة مع بيانات كاملة:
  - اسم الصف
  - المرحلة (ابتدائي، متوسط، ثانوي)
  - المادة الدراسية
  - العام الدراسي
  - الفصل الدراسي
  - وصف اختياري
- تعديل بيانات الصفوف الموجودة
- حذف الصفوف (مع حذف تلقائي للطلاب والدرجات المرتبطة)
- عرض قائمة الصفوف مع عدد الطلاب في كل صف

### 4. إدارة الطلاب
- إضافة طلاب جدد مع معلومات شاملة:
  - رقم الطالب (فريد)
  - الاسم الكامل
  - الصف الدراسي
  - تاريخ الميلاد
  - الجنس
  - البريد الإلكتروني (اختياري)
  - رقم جوال ولي الأمر (اختياري)
- تعديل بيانات الطلاب
- حذف الطلاب (مع حذف تلقائي للدرجات)
- فلترة الطلاب حسب الصف
- البحث عن طلاب معينين
- عرض الطلاب في جدول منظم

### 5. أدوات التقويم
- إنشاء أدوات تقويم متنوعة:
  - اختبارات
  - واجبات
  - مشاركة
  - مشاريع
  - أنشطة
- تحديد الدرجة العظمى لكل أداة
- تحديد وزن كل أداة في الدرجة النهائية
- ربط كل أداة بصف معين
- تعديل وحذف أدوات التقويم

### 6. كشف الدرجات
- إدخال درجات الطلاب بشكل سهل وسريع
- عرض جدول تفاعلي للدرجات
- حساب تلقائي للنسب المئوية
- إمكانية إضافة ملاحظات لكل درجة
- فلترة حسب الصف وأداة التقويم

### 7. لوحة التحكم والإحصائيات
- عرض إحصائيات فورية:
  - إجمالي الصفوف
  - إجمالي الطلاب
  - إجمالي أدوات التقويم
  - نسبة الإكمال
- عرض الأنشطة الأخيرة مع الوقت
- قائمة بالصفوف النشطة

### 8. قاعدة البيانات المحلية (IndexedDB)
- تخزين جميع البيانات محلياً في المتصفح
- لا حاجة لخادم أو اتصال بالإنترنت
- هيكل منظم للبيانات:
  - جدول الصفوف
  - جدول الطلاب
  - جدول أدوات التقويم
  - جدول الدرجات
  - جدول الأنشطة
- فهرسة ذكية للبحث السريع
- إدارة آمنة للمعاملات

### 9. تسجيل الأنشطة
- تتبع جميع العمليات التي تتم في النظام
- عرض سجل بالأنشطة الأخيرة
- معرفة متى تم إضافة أو تعديل أو حذف البيانات

## الهيكل التقني

### الملفات الرئيسية

#### `index.html`
- الصفحة الرئيسية للنظام
- تحتوي على جميع الصفحات والنوافذ المنبثقة
- واجهة مستخدم كاملة بالعربية

#### `styles.css`
- تصميم احترافي متجاوب
- استخدام CSS Variables للألوان والمتغيرات
- تصميم متجاوب لجميع أحجام الشاشات
- رسوم متحركة سلسة
- تدرجات لونية جذابة

#### `db.js`
- إدارة قاعدة بيانات IndexedDB
- دوال كاملة للعمليات الأساسية (CRUD)
- دوال متخصصة لكل نوع بيانات
- معالجة الأخطاء بشكل احترافي

#### `app.js`
- منطق التطبيق الرئيسي
- إدارة التنقل بين الصفحات
- معالجة النماذج والأحداث
- ربط الواجهة بقاعدة البيانات
- حسابات ذكية للإحصائيات

## كيفية الاستخدام

### 1. التشغيل
- افتح ملف `index.html` في متصفح حديث (Chrome, Firefox, Edge, Safari)
- لا حاجة لتثبيت أي برامج إضافية
- يعمل بدون اتصال بالإنترنت (بعد التحميل الأول)

### 2. إضافة صف دراسي
1. اذهب إلى قسم "إدارة الصفوف"
2. اضغط على "إضافة صف جديد"
3. املأ البيانات المطلوبة
4. اضغط على "حفظ"

### 3. إضافة طلاب
1. اذهب إلى قسم "إدارة الطلاب"
2. اضغط على "إضافة طالب جديد"
3. املأ البيانات واختر الصف
4. اضغط على "حفظ"

### 4. إنشاء أداة تقويم
1. اذهب إلى قسم "أدوات التقويم"
2. اضغط على "إضافة أداة تقويم"
3. اختر نوع الأداة والصف
4. حدد الدرجة العظمى والوزن
5. اضغط على "حفظ"

### 5. إدخال الدرجات
1. اذهب إلى قسم "كشف الدرجات"
2. اختر الصف وأداة التقويم
3. أدخل درجات الطلاب
4. اضغط على "حفظ" لكل طالب

## الدعم والمساعدة

### حل المشاكل الشائعة

**المشكلة: البيانات لا تحفظ**
- تأكد من أن المتصفح يدعم IndexedDB
- تحقق من أنك لم تفعل وضع التصفح الخاص
- امسح ذاكرة التخزين المؤقت وأعد المحاولة

**المشكلة: التصميم لا يظهر بشكل صحيح**
- تأكد من تحميل ملف styles.css
- حاول تحديث الصفحة (Ctrl+F5)
- تحقق من أن المتصفح محدّث

**المشكلة: النظام بطيء**
- قد يحدث هذا مع كمية كبيرة من البيانات
- حاول حذف البيانات القديمة
- استخدم متصفحاً أسرع

## الأمان والخصوصية

- جميع البيانات تُخزّن محلياً على جهازك فقط
- لا يتم إرسال أي بيانات إلى خوادم خارجية
- يمكنك استخدام النظام بدون اتصال بالإنترنت
- يُنصح بأخذ نسخ احتياطية دورية
