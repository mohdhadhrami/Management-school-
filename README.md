# نظام سجل الدرجات الإلكتروني الاحترافي

نظام متكامل لإدارة درجات الطلاب في المدارس باستخدام التقنيات الحديثة.

## المميزات الرئيسية

### 1. التصميم الاحترافي
- واجهة مستخدم عربية متكاملة ومتجاوبة
- تصميم حديث يعمل على جميع الأجهزة (حاسوب، تابلت، هاتف)
- ألوان متناسقة وواضحة مع تدرجات جذابة
- أيقونات Font Awesome للتوضيح

### 2. الهيكل التنظيمي
- شريط جانبي للتنقل السريع بين الأقسام
- شريط علوي بتصميم جذاب
- لوحة تحكم رئيسية مع إحصائيات مباشرة
- صفحات منفصلة لكل وظيفة

### 3. إدارة الصفوف الدراسية
- إضافة صفوف جديدة مع بيانات كاملة:
  - اسم الصف
  - المرحلة (ابتدائي، متوسط، ثانوي)
  - المادة الدراسية
  - العام الدراسي
  - الفصل الدراسي
  - وصف اختياري
- تعديل بيانات الصفوف الموجودة
- حذف الصفوف (مع حذف تلقائي للطلاب والدرجات المرتبطة)
- عرض قائمة الصفوف مع عدد الطلاب في كل صف

### 4. إدارة الطلاب
- إضافة طلاب جدد مع معلومات أساسية:
  - الرقم المدرسي (فريد - مثال: 411615650999)
  - الاسم الكامل (مثال: عزان بن محمد بن احمد بن مطر الحضرمي)
  - الصف الدراسي
  - الجنسية (مثال: عماني)
  - المنطقة السكنية (مثال: فرق)
  - الهاتف النقال (مثال: 99887897)
- تعديل بيانات الطلاب
- حذف الطلاب (مع حذف تلقائي للدرجات)
- فلترة الطلاب حسب الصف
- البحث عن طلاب معينين
- عرض الطلاب في جدول منظم

### 5. أدوات التقويم
- إنشاء أدوات تقويم متنوعة:
  - اختبارات
  - واجبات
  - مشاركة
  - مشاريع
  - أنشطة
- تحديد الدرجة العظمى لكل أداة
- تحديد وزن كل أداة في الدرجة النهائية
- ربط كل أداة بصف معين
- تعديل وحذف أدوات التقويم

### 6. كشف الدرجات
- إدخال درجات الطلاب بشكل سهل وسريع
- عرض جدول تفاعلي للدرجات
- حساب تلقائي للنسب المئوية
- إمكانية إضافة ملاحظات لكل درجة
- فلترة حسب الصف وأداة التقويم

### 7. لوحة التحكم والإحصائيات
- عرض إحصائيات فورية:
  - إجمالي الصفوف
  - إجمالي الطلاب
  - إجمالي أدوات التقويم
  - نسبة الإكمال
- عرض الأنشطة الأخيرة مع الوقت
- قائمة بالصفوف النشطة

### 8. قاعدة البيانات المحلية (IndexedDB)
- تخزين جميع البيانات محلياً في المتصفح
- لا حاجة لخادم أو اتصال بالإنترنت
- هيكل منظم للبيانات:
  - جدول الصفوف
  - جدول الطلاب
  - جدول أدوات التقويم
  - جدول الدرجات
  - جدول الأنشطة
- فهرسة ذكية للبحث السريع
- إدارة آمنة للمعاملات

### 9. تسجيل الأنشطة
- تتبع جميع العمليات التي تتم في النظام
- عرض سجل بالأنشطة الأخيرة
- معرفة متى تم إضافة أو تعديل أو حذف البيانات

### 10. استيراد وتصدير البيانات (جديد!)
- **استيراد الطلاب من Excel:**
  - دعم ملفات .xlsx و .xls
  - قالب Excel جاهز للتحميل يحتوي على:
    - م (رقم تسلسلي)
    - الاسم
    - الرقم المدرسي
    - الجنسية
    - المنطقة السكنية
    - الهاتف النقال
  - معالجة ذكية لأسماء الأعمدة بالعربية والإنجليزية
  - تقرير مفصل عن نتائج الاستيراد مع الأخطاء إن وجدت
  - أمثلة عمانية في القالب لسهولة الاستخدام

- **تصدير البيانات بصيغ متعددة:**
  - **JSON**: ملف بيانات منظم للتكامل مع أنظمة أخرى
  - **CSV**: ملف نصي مفصول بفواصل لاستيراده في برامج أخرى
  - **XML**: صيغة XML منظمة للتطبيقات المتقدمة
  - **Excel**: ملف جداول بيانات منسق بشكل احترافي

- **تصدير حسب النوع:**
  - تصدير قائمة الطلاب الكاملة
  - تصدير درجات صف معين في أداة تقويم محددة
  - تصدير جميع بيانات النظام كنسخة احتياطية

### 11. اختيار صفوف متعددة لأدوات التقويم (جديد!)
- إمكانية تطبيق أداة تقويم واحدة على عدة صفوف
- واجهة checkboxes سهلة الاستخدام
- توفير الوقت عند إنشاء نفس الاختبار لصفوف متعددة
- عرض معلومات كل صف (المرحلة والمادة) عند الاختيار

### 12. التكامل مع البوابة التعليمية (جديد!)
- **إعدادات البوابة:**
  - حفظ رقم المدرسة في البوابة
  - حفظ رقم المعلم في البوابة
  - إدخال رابط API البوابة
  - تخزين مفتاح API بشكل آمن
  - حفظ الإعدادات محلياً لاستخدامها لاحقاً

- **إرسال البيانات للبوابة:**
  - تجهيز البيانات بالتنسيق المطلوب للبوابة
  - إرسال الدرجات مباشرة عبر API
  - تحميل ملف JSON جاهز إذا لم يكن API متاحاً
  - معلومات شاملة في البيانات المُرسلة:
    - بيانات المدرسة والمعلم
    - معلومات الصف والمادة
    - تفاصيل أداة التقويم
    - درجات جميع الطلاب مع النسب المئوية
    - حالة كل طالب (ناجح/راسب/معلق)

- **الأمان:**
  - لا يتم إرسال أي بيانات بدون تأكيد المستخدم
  - إمكانية مراجعة البيانات قبل الإرسال
  - تشفير الاتصال عبر HTTPS
  - حفظ سجل بجميع عمليات الإرسال

### 13. نظام الحضور والغياب (جديد! v3.0)
- **تسجيل الحضور:**
  - تسجيل سريع لحضور صف كامل دفعة واحدة
  - ثلاث حالات: حاضر، غائب، متأخر
  - إضافة ملاحظات لكل طالب
  - تحديد التاريخ والصف
  - حفظ تلقائي للبيانات

- **الإحصائيات والتقارير:**
  - عرض فوري لإحصائيات الحضور
  - عدد الحاضرين والغائبين والمتأخرين
  - إجمالي عدد الطلاب
  - فلترة حسب الصف والتاريخ
  - تصدير سجلات الحضور

- **قاعدة البيانات:**
  - جدول مخصص للحضور
  - فهرسة ذكية لسرعة البحث
  - منع التكرار لنفس الطالب في نفس التاريخ
  - ربط مع بيانات الطلاب والصفوف

### 14. نظام السلوكيات والملاحظات (جديد! v3.0)
- **تسجيل الملاحظات:**
  - ملاحظات إيجابية: تفوق دراسي، مشاركة فعالة، سلوك حسن، مساعدة زملاء
  - ملاحظات تحتاج تحسين: حديث جانبي، عدم إحضار الكتاب، نوم في الحصة، عدم الانتباه، تأخر، عدم الالتزام
  - ملاحظات خطيرة: مشاجرة، إساءة للمعلم، تخريب ممتلكات
  - مستويات: إيجابي ✅، بسيط ⚠️، متوسط 🔶، خطير 🔴
  - تسجيل الإجراء المتخذ

- **إشعارات واتساب:**
  - إرسال إشعارات فورية لأولياء الأمور
  - دعم واتساب API للإرسال التلقائي
  - فتح واتساب ويب كبديل
  - قوالب رسائل جاهزة
  - سجل بجميع الإشعارات المرسلة

- **الفلترة والبحث:**
  - فلترة حسب الصف
  - فلترة حسب نوع الملاحظة
  - فلترة حسب الفترة الزمنية
  - عرض منظم للملاحظات مع الألوان المميزة

- **قاعدة البيانات:**
  - جدول السلوكيات مع فهرسة شاملة
  - جدول إشعارات واتساب
  - ربط مع بيانات الطلاب
  - تتبع حالة الإرسال

## الهيكل التقني

### الملفات الرئيسية

#### `index.html`
- الصفحة الرئيسية للنظام
- تحتوي على جميع الصفحات والنوافذ المنبثقة
- واجهة مستخدم كاملة بالعربية

#### `styles.css`
- تصميم احترافي متجاوب
- استخدام CSS Variables للألوان والمتغيرات
- تصميم متجاوب لجميع أحجام الشاشات
- رسوم متحركة سلسة
- تدرجات لونية جذابة

#### `db.js`
- إدارة قاعدة بيانات IndexedDB
- دوال كاملة للعمليات الأساسية (CRUD)
- دوال متخصصة لكل نوع بيانات
- معالجة الأخطاء بشكل احترافي

#### `app.js`
- منطق التطبيق الرئيسي
- إدارة التنقل بين الصفحات
- معالجة النماذج والأحداث
- ربط الواجهة بقاعدة البيانات
- حسابات ذكية للإحصائيات

#### `import-export.js` (جديد!)
- نظام الاستيراد والتصدير المتقدم
- دعم قراءة وكتابة ملفات Excel باستخدام SheetJS
- تصدير بصيغ متعددة (JSON, CSV, XML, Excel)
- معالجة ذكية للبيانات وتحويل التنسيقات
- التكامل مع API البوابة التعليمية
- قالب Excel جاهز للتحميل

#### `app-extensions.js` (جديد!)
- إضافات ووظائف متقدمة للتطبيق
- معالجة أحداث الاستيراد والتصدير
- إدارة إعدادات البوابة التعليمية
- دعم الصفوف المتعددة لأدوات التقويم
- واجهات تفاعلية لتقدم العمليات

#### `daily-tracking.js` (جديد! v3.0)
- نظام المتابعة اليومية الكامل
- إدارة الحضور والغياب
- نظام السلوكيات والملاحظات
- إشعارات واتساب لأولياء الأمور
- فلترة وتصدير البيانات
- واجهات تفاعلية لإدخال البيانات

### المكتبات الخارجية

#### SheetJS (xlsx.js)
- مكتبة قوية للتعامل مع ملفات Excel
- قراءة وكتابة ملفات .xlsx و .xls
- تحويل البيانات بين صيغ مختلفة
- النسخة المستخدمة: 0.18.5
- CDN: `https://cdnjs.cloudflare.com/ajax/libs/xlsx/0.18.5/xlsx.full.min.js`

## كيفية الاستخدام

### 1. التشغيل
- افتح ملف `index.html` في متصفح حديث (Chrome, Firefox, Edge, Safari)
- لا حاجة لتثبيت أي برامج إضافية
- يعمل بدون اتصال بالإنترنت (بعد التحميل الأول)

### 2. إضافة صف دراسي
1. اذهب إلى قسم "إدارة الصفوف"
2. اضغط على "إضافة صف جديد"
3. املأ البيانات المطلوبة
4. اضغط على "حفظ"

### 3. إضافة طلاب
1. اذهب إلى قسم "إدارة الطلاب"
2. اضغط على "إضافة طالب جديد"
3. املأ البيانات واختر الصف
4. اضغط على "حفظ"

### 4. إنشاء أداة تقويم
1. اذهب إلى قسم "أدوات التقويم"
2. اضغط على "إضافة أداة تقويم"
3. اختر نوع الأداة والصف
4. حدد الدرجة العظمى والوزن
5. اضغط على "حفظ"

### 5. إدخال الدرجات
1. اذهب إلى قسم "كشف الدرجات"
2. اختر الصف وأداة التقويم
3. أدخل درجات الطلاب
4. اضغط على "حفظ" لكل طالب

### 6. استيراد الطلاب من Excel (جديد!)
1. اذهب إلى قسم "إدارة الطلاب"
2. اضغط على "تحميل القالب" لتنزيل قالب Excel
3. املأ القالب ببيانات الطلاب باستخدام الحقول التالية:
   - **م**: رقم تسلسلي (1، 2، 3، ...)
   - **الاسم**: الاسم الكامل (مثال: عزان بن محمد بن احمد بن مطر الحضرمي)
   - **الرقم المدرسي**: رقم فريد (مثال: 411615650999)
   - **الجنسية**: (مثال: عماني)
   - **المنطقة السكنية**: (مثال: فرق)
   - **الهاتف النقال**: (مثال: 99887897)
4. اضغط على "استيراد من Excel"
5. اختر الملف الذي قمت بملئه
6. انتظر حتى يكتمل الاستيراد
7. راجع تقرير النتائج وتحقق من الأخطاء إن وجدت

**ملاحظات مهمة:**
- يمكن استخدام أسماء أعمدة بالعربية أو الإنجليزية
- الرقم المدرسي يجب أن يكون فريداً
- الحقول المطلوبة: الاسم والرقم المدرسي
- القالب يحتوي على أمثلة عمانية لسهولة الفهم

### 7. تصدير البيانات (جديد!)
1. **تصدير الطلاب:**
   - اذهب إلى "إدارة الطلاب"
   - اضغط على "تصدير"
   - اختر الصيغة المطلوبة (JSON, CSV, XML, Excel)

2. **تصدير الدرجات:**
   - اذهب إلى "كشف الدرجات"
   - اختر الصف وأداة التقويم
   - اضغط على "تصدير"
   - اختر الصيغة المطلوبة

**صيغ التصدير المتاحة:**
- **JSON**: للتكامل مع تطبيقات أخرى أو كنسخة احتياطية
- **CSV**: لفتحه في Excel أو Google Sheets
- **XML**: للأنظمة التي تتطلب XML
- **Excel**: ملف .xlsx منسق بشكل احترافي

### 8. التكامل مع البوابة التعليمية (جديد!)
1. **ضبط الإعدادات:**
   - اذهب إلى "الإعدادات"
   - اضغط على "إعدادات البوابة"
   - أدخل رقم المدرسة ورقم المعلم
   - أدخل رابط API البوابة (إذا كان متاحاً)
   - أدخل مفتاح API
   - اضغط على "حفظ الإعدادات"

2. **إرسال الدرجات:**
   - اذهب إلى "كشف الدرجات"
   - اختر الصف وأداة التقويم
   - تأكد من إدخال جميع الدرجات
   - اضغط على "إرسال للبوابة"
   - راجع البيانات التي سيتم إرسالها
   - أكد الإرسال

**ملاحظات:**
- إذا لم يكن لديك رابط API، سيتم تحميل ملف JSON يمكنك رفعه يدوياً للبوابة
- جميع البيانات المرسلة تكون بتنسيق قياسي متوافق
- يمكنك مراجعة البيانات قبل الإرسال
- سيتم إظهار رسالة تأكيد بعد نجاح الإرسال

### 9. اختيار صفوف متعددة لأداة التقويم (جديد!)
1. عند إضافة أداة تقويم جديدة
2. بدلاً من اختيار صف واحد، ستجد قائمة بجميع الصفوف
3. حدد جميع الصفوف التي تريد تطبيق الأداة عليها
4. اضغط على "حفظ"
5. سيتم إنشاء نسخة من الأداة لكل صف محدد تلقائياً

**فوائد:**
- توفير الوقت عند إنشاء نفس الاختبار لعدة صفوف
- ضمان التوحيد في أدوات التقويم
- سهولة الإدارة والمتابعة

### 10. المتابعة اليومية - الحضور والغياب (جديد! v3.0)
1. اذهب إلى قسم "الحضور والغياب"
2. اضغط على "تسجيل الحضور"
3. اختر الصف والتاريخ
4. سيتم عرض قائمة بجميع طلاب الصف
5. حدد حالة كل طالب (حاضر/غائب/متأخر)
6. أضف ملاحظات إذا لزم الأمر
7. اضغط على "حفظ الحضور"

**عرض سجلات الحضور:**
1. اختر الصف من القائمة المنسدلة
2. اختر التاريخ
3. اضغط على "تحميل"
4. سيتم عرض سجل الحضور مع الإحصائيات

**تصدير سجلات الحضور:**
- اضغط على "تصدير" لتنزيل سجلات الحضور بصيغة Excel

### 11. المتابعة اليومية - السلوكيات والملاحظات (جديد! v3.0)
1. اذهب إلى قسم "السلوكيات والملاحظات"
2. اضغط على "إضافة ملاحظة"
3. املأ البيانات:
   - اختر الطالب
   - اختر التاريخ
   - اختر نوع الملاحظة
   - حدد مستوى الملاحظة (إيجابي/بسيط/متوسط/خطير)
   - اكتب تفاصيل الملاحظة
   - سجل الإجراء المتخذ
4. (اختياري) حدد خيار "إرسال إشعار واتساب لولي الأمر"
5. اضغط على "حفظ"

**فلترة الملاحظات:**
- فلترة حسب الصف
- فلترة حسب نوع الملاحظة
- فلترة حسب الفترة الزمنية (من تاريخ - إلى تاريخ)

**إشعارات واتساب:**
1. عند إضافة ملاحظة، يمكنك تحديد خيار "إرسال إشعار واتساب"
2. سيتم إرسال رسالة تلقائياً إلى جوال ولي الأمر (إذا كان مسجلاً)
3. الرسالة تحتوي على:
   - اسم الطالب
   - نوع الملاحظة
   - التاريخ
   - تفاصيل الملاحظة
   - الإجراء المتخذ

**إعدادات واتساب:**
1. اذهب إلى "الإعدادات"
2. اضغط على "إعدادات واتساب"
3. أدخل رابط API (اختياري) للإرسال التلقائي
4. أو اترك الحقول فارغة لفتح واتساب ويب مباشرة

## الدعم والمساعدة

### حل المشاكل الشائعة

**المشكلة: البيانات لا تحفظ**
- تأكد من أن المتصفح يدعم IndexedDB
- تحقق من أنك لم تفعل وضع التصفح الخاص
- امسح ذاكرة التخزين المؤقت وأعد المحاولة

**المشكلة: التصميم لا يظهر بشكل صحيح**
- تأكد من تحميل ملف styles.css
- حاول تحديث الصفحة (Ctrl+F5)
- تحقق من أن المتصفح محدّث

**المشكلة: النظام بطيء**
- قد يحدث هذا مع كمية كبيرة من البيانات
- حاول حذف البيانات القديمة
- استخدم متصفحاً أسرع
